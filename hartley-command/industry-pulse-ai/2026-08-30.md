5. **CORPUS GAP in the agent-architecture category — the arXiv literature on writable persistent agent memory has converged on a lifecycle security model arguing that memory security CANNOT be retrofitted at retrieval or execution time and must be anchored at write and store time, and none of it appears anywhere in this corpus** ([arxiv.org](https://arxiv.org/abs/2604.16548)) — 'A Survey on Long-Term Memory Security in LLM Agents: Attacks, Defenses, and Governance Across the Memory Lifecycle' (2604.16548, Lin et al., submitted Apr 17 2026, revised Jun 11 2026) argues that writable, cross-session persistent memory creates a threat landscape qualitatively different from input-centric concerns like prompt injection and RAG poisoning, because agent memory is stateful, persistent and propagating.
