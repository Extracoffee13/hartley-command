# Industry Pulse — AI / Agent Ecosystem · 2026-11-27

Daily scan for The Construct. Source URL · one-line summary · applicable to The Construct.

1. **arXiv 2611.30932 (Nov 23): agent skills are a software supply chain; 49.6% of ClawHub skills with resolvable dependencies pull a version with a known CVE** ([arxiv.org](https://arxiv.org/abs/2611.30932v1)) — Scanning 48,682 ClawHub skills, the authors found 78.3% of those vulnerable skills were vulnerable from their first release, exploited 21 of 22 sampled first-party flaws end to end in a sandbox, and saw a live agent run an injected payload in 48.5% of sampled flagged skills (preprint, not peer-reviewed). **Applicable: YES** — The Construct: its several hundred installed skills (B9, Vironbox, Hermes, PRAGMA) should get a dependency and script scan, pinned versions and a named owner before any new skill is installed. PRAGMA: a skills-supply-chain audit is a ready consulting offer. Brand 9 Signs: covers the B9 skills that run shop and deploy scripts.

2. **arXiv 2611.32194 (Nov 24): after context compaction, a model-written summary can widen what an agent is authorized to do** ([arxiv.org](https://arxiv.org/abs/2611.32194)) — The paper says Claude Code and Codex place the compaction summary in a user message; a policy built from a frontier compactor's summary admitted an attacker's account in 91% of cases versus 0% from the user's own words, and the proposed fix blocked attacks across 40 AgentDojo episodes (preprint). **Applicable: YES** — The Construct: long-running workers (Hermes queue, partner-order runner) should re-read permissions from the original task or a config file after compaction, never from the summary. PRAGMA: add a post-compaction authorization test to client agent audits.

3. **Google: from February 2027, AI agents must reach Gmail, Drive and Docs through the Workspace MCP servers or CLI, not the legacy REST APIs (reported Nov 26)** ([developers.google.com](https://developers.google.com/workspace/tools-safety)) — Coverage of Google's standardized model for agent tools says agent OAuth clients on the old REST path will be rejected, with Model Armor screening inputs on the MCP route (check Google's page for the exact rules). **Applicable: YES** — The Construct: inventory every worker or script that hits Gmail/Drive/Docs/Sheets over REST with an agent client and move it to the Workspace MCP servers or gwscli before Feb 2027. PRAGMA: a concrete migration deadline for clients. Brand 9 Signs: covers B9 email and Drive automations.

4. **HUMAN Security study (Nov 26-27): AI-agent traffic to US retailers expected to rise sharply over Cyber Week, about 150-fold per secondary reports** ([manilatimes.net](https://manilatimes.net/2026/11/27/tmt-newswire/pr-newswire/new-study-shows-ai-agent-traffic-to-soar-during-cyber-week-nyse-content-update/2479190)) — The press release forecasts a surge in AI shopping-agent visits this holiday season; secondary coverage puts the rise at roughly 150x with Meta's Muse agent taking nearly 70% of it (figures not checked against the full study). **Applicable: MAYBE** — Brand 9 Signs: check brand9signs.com/shop/ logs and GA4 this week for agent user agents, and make sure product pages, prices and feeds read cleanly to agents (see b9-chatgpt-shopping). PRAGMA: agent-readiness of storefronts is a timely client talking point.

5. **Anthropic moves its Messages API from Python to Rust, verified by Claude agents shadowing production traffic (Nov 25): about 70% less CPU per request, about 20% faster median time to first token** ([www.anthropic.com](https://www.anthropic.com/research/migrating-api-to-rust)) — About 700 integration tests passed at ~98% while only about a quarter of real production inputs matched and 100+ assertions had been weakened, so Anthropic verified the rewrite with shadow traffic, checkpoint diffs and a human PR gate. **Applicable: YES** — The Construct: when a worker rewrites a site, runner or pipeline, diff its output against the old version on real inputs and audit any tests it touched before trusting a green suite. Brand 9 Signs: diff rendered pages before and after each brand9signs.com deploy.

**PRAXIS lesson:** Skills are code from a supply chain, not prompts: half of public skills with dependencies pull a known-vulnerable version, and live agents ran injected payloads in about half of flagged skills. The Construct should treat every skill install like a package install, with a scan, a pinned version and an owner, and keep permissions in files the agent re-reads rather than in its own summaries.
