# Industry Pulse — AI / Agent Ecosystem · 2026-11-13

Daily scan for The Construct. Source URL · one-line summary · applicable to The Construct.

1. **arXiv 2611.01976 'The Tool Update Gap': malicious tool updates hit 97.6% attack success across 7 agent frameworks, Claude Code included** ([arxiv.org](https://arxiv.org/abs/2611.01976)) — The ETUDE attack hides malicious code inside updates to tools an agent already trusts; because the code runs outside the model's context, in-context prompt-injection defenses miss it. It reached 97.6% attack success while still completing 95.9% of legitimate tasks across Gemini CLI, Codex CLI, Claude Code and four other frameworks, and the authors say existing defenses are insufficient. **Applicable: YES** — The Construct: pin versions of every MCP server, plugin and skill, and re-review on update instead of auto-trusting new versions; the unattended loops are exactly the setting this attack targets. PRAGMA: 'tool supply-chain review' is a concrete client security offer. Brand 9 Signs: applies through the shop and ops agents.

2. **Claude Code 2.1.323: experimental Code Mode (Claude writes JavaScript to call its tools) + plugin version-range gating** ([releasebot.io](https://releasebot.io/updates/anthropic)) — First seen Nov 13: an opt-in Code Mode where Claude writes JavaScript to call its tools rather than issuing one tool call at a time; plugin.json now accepts engines["claude-code"] to gate a plugin to supported Claude Code versions; and managed settings add CLAUDE_CODE_AUTO_MODE_MODEL for Claude Desktop on third-party providers. **Applicable: YES** — The Construct: trial Code Mode on multi-step tool chains (render, publish, order loops) and compare tokens per successful task; add engines version ranges to the Construct and b9 plugins so they don't break silently on upgrade. PRAGMA: a cost lever to show clients. Brand 9 Signs: indirect.

3. **Anthropic (Nov 12): self-hosted Claude Managed Agents in private beta + Claude for Manufacturing plugin** ([releasebot.io](https://releasebot.io/updates/anthropic)) — Managed Agents can now run the full service, including harness, sandboxes, credentials and session history, in a customer's own cloud or on-prem, with the customer choosing where model requests go (access via the Anthropic account team). Separately, Claude for Manufacturing ships as a plugin with 17 skills and connectors for Autodesk Fusion, Infor, Microsoft 365 and Oracle NetSuite on Team and Enterprise. **Applicable: MAYBE** — PRAGMA: self-hosted agents remove the data-residency objection for regulated or cautious clients, and the Manufacturing plugin is a template for packaging a vertical as skills + connectors. Brand 9 Signs: the Fusion connector is worth a look for CNC/fabrication work. The Construct: no need to self-host today.

4. **Plurai raises $13M seed (Nov 13) for pre-launch AI-agent testing via digital twins** ([securitybrief.news](https://securitybrief.news/story/plurai-raises-usd-13-million-for-ai-agent-testing-platform)) — Team8-led seed for a New York startup that builds a digital twin of an agent and its environment, runs simulated adversarial interactions to find failures, generates fixes, and trains small models to act as evaluators and guardrails; the platform is now open to all developers with a free tier. **Applicable: YES** — The Construct: run the unattended loops (order, publish, email) against a simulated adversarial twin before trusting new tool or skill versions, which is the practical answer to today's Tool Update Gap paper; the free tier makes a trial cheap. PRAGMA: 'test the agent before customers do' is a sellable operator service. Brand 9 Signs: applies to the customer-facing shop and email agents.

5. **Google Cloud now co-maintains MCP and Agent Skills under the Linux Foundation's AAIF** ([aiagentsdirectory.com](https://aiagentsdirectory.com/news/ai-agents-news-brief-november-12-2026)) — Reported Nov 12 via the Google Open Source Blog: Google Cloud's Kurtis Van Gent is a co-maintainer of MCP and Agent Skills within the Agentic AI Foundation, putting Google alongside Anthropic in stewarding both standards. **Applicable: MAYBE** — The Construct: skills and MCP servers built to the open spec should port across Claude and Gemini, so keep them spec-clean rather than Claude-only. PRAGMA: a cross-vendor standards story for clients worried about lock-in. Brand 9 Signs: no.

**PRAXIS lesson:** Treat every tool, MCP server and plugin update as new code: pin versions, gate upgrades and re-test the agent against a simulated adversarial run before an unattended loop trusts it, because malicious updates run outside the model's context where prompt-injection defenses can't see them. Once a multi-step tool chain is stable, move it into code (Code Mode, scripts) to cut tokens and shrink what the agent has to be trusted with.
