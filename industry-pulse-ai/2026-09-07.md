4. **HOW the tools are shaped changes behaviour as much as WHAT they do — 11,700 trajectories across six tool architectures with capability held constant: structured low-level interfaces improve consistency up to 4.7×, and CodeAct-style Python interfaces hit the same task performance with 41.6% fewer steps and 56.3% lower token usage** ([arxiv.org/abs/2608.11386](https://arxiv.org/abs/2608.11386)) — Primary abstract fetched; submitted 11 Aug 2026, so out of window and named for the reading queue, not as news. *The Devil Is in the Interface* (Xu, Saghir, Wu, Côté, Wang, Lakkaraju, Pei, Zhang) isolates a variable this fleet has never controlled for: not which capabilities an agent has, but how they are organised and exposed. Holding the underlying information and actions similar across six architectures and three actors: versus a baseline with only a bash tool, **more structured low-level interfaces improve consistency across repeated attempts by up to 4.7×**; **natural-language search broadens repository exploration and increases access to relevant files by more than 11%**; **Python CodeAct-style interfaces achieve similar task performance with 41.6% fewer steps and 56.3% lower token usage**. The negative result is the one that stings: "lightweight text-based cognitive-scaffolding tools, such as tools that let the agent record intermediate reasoning, have limited effect on actor behavior." **Applicable: MAYBE**, tending to YES on a second read, and it slots directly behind bullet 3 rather than competing with it. `/skill-doctor` answers *which skills are dead weight*; the canary paper carried yesterday (2608.04719) answers *whether the live ones are selected correctly*; this one answers *whether they are shaped correctly at all* — and it is the only one of the three that puts a token number on the answer. **PRAXIS lesson, amended at the third fire:** the second fire's rule was that a single surface treated as a census is not a sweep. This report led at 06:00 with Deadbugz as "the most directly actionable item in two weeks," and it is; but it is an instance of RUG PULL, an attack class the NSA and DoD named in a joint advisory on 2026-06-02, with documented victims (Postmark, Smithery) predating today by months. So the rule is: BEFORE CALLING AN ITEM A LEAD, ASK WHAT CLASS IT BELONGS TO AND WHEN THAT CLASS WAS FIRST NAMED.
