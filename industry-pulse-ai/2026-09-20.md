An attacker who controls the plugin's repo creates a *branch* whose name is the exact 40-hex pinned SHA and makes it the default; git prefers a ref over an object of the same name, prints only an "ambiguous refname" warning, and checks out attacker code while the agent reports a successful install **at the pinned commit**. Gemini CLI has a separate variant: `git checkout FETCH_HEAD` resolves to a default branch literally named `FETCH_HEAD`, discarding the fetched commit. The fix is one assertion — `test "$(git rev-parse HEAD)" = "<pinned-sha>" || abort` — and **it must run inside the agent, because the pin is resolved on the client; no marketplace can enforce it.** What makes it zero-click is that the same checkout **re-runs on background plugin auto-update, which is the default in Claude Code and Codex**, so a bumped pin reaches already-installed plugins with no install step and no prompt. **Patch status: Anthropic fixed Claude Code in 2.1.179, confirmed 2026-06-17. OpenAI fixed Codex in 0.146.0, verified 2026-08-12. Microsoft has shipped nothing for Copilot.
