# Industry Pulse — AI / Agent Ecosystem · 2026-11-22

Daily scan for The Construct. Source URL · one-line summary · applicable to The Construct. (Evening refresh: added OpenRouter provider off-boarding, Walmart Agent Gateway, Cairn autonomous exploit; LangSmith Tool Gateway replaces the Cognition funding item.)

1. **OpenRouter off-boards Novita, Phala and Together and pulls 125 endpoints from zero-data-retention after canary tests caught prompt logging (Nov 22)** ([openrouter.ai](https://openrouter.ai/blog/announcements/data-processing-incidents-on-inference-providers/)) — Following HD Moore's roughly 2 million canary-token prompts across inference services, OpenRouter reports data-processing incidents at several providers, removed three of them, and stripped ZDR eligibility from 125 endpoints. **Applicable: YES** — The Construct: Hermes delegation workers run deepseek/deepseek-v4-flash through OpenRouter with provider routing left on auto, and open-weight DeepSeek is commonly served by exactly these hosts. Pin an allow-list of providers with ZDR enforced, keep client files and credentials out of cheap-worker prompts, and check past delegation logs for which providers served them. PRAGMA: a concrete, dated reason clients need a provider policy, not just a model choice.

2. **Walmart opens an Agent Gateway for outside shopping agents, with customer-set permissions and spending limits; Sparky usage up about 129% (Nov 21)** ([fourweekmba.com](https://fourweekmba.com/ai-walmart-sparky-use-up-129-in-a-year-baskets-40-larger/)) — Walmart will let external agents (Meta's Muse among them) connect through a gateway that enforces what each agent may do and spend, as use of its own Sparky agent more than doubled year over year. **Applicable: YES** — Brand 9 Signs: the largest US retailer is building a front door for buyer agents; the shop should expose clean product, pricing and order endpoints (feeds or MCP) so agents can quote and order signs. PRAGMA: the gateway pattern (per-agent scopes plus spend caps) is the template to sell clients exposing their own systems to agents.

3. **Amazon: a suspected state actor used the open-source Cairn agent framework to find and exploit a zero-day on its own, root shell in about 11 minutes (Nov 20)** ([www.bleepingcomputer.com](https://www.bleepingcomputer.com/news/security/hackers-use-autonomous-ai-tool-cairn-to-find-zero-day-take-over-server/)) — Amazon Threat Intelligence says the attacker's agent autonomously found a path-traversal bug in MONAI Label and took over the server; MONAI has shipped a patch. **Applicable: YES** — The Construct: anything we expose (dashboard endpoints, MCP servers, render nodes, the B9 site) now faces agent-speed probing and patch windows shrink to hours. Keep internal MCP servers off the public internet, have the site-health sentinel test path-traversal and file-read routes, and keep dependencies current. PRAGMA: lead client security conversations with this case.

4. **Gemini API adds Tool Retrieval (preview, Nov 20): agents load a tool's full schema only when they need it** ([blog.google](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/)) — Google's Tool Retrieval preview lets agents with hundreds of tools keep idle tools as short stubs and pull in the full parameter schema on demand, cutting context overhead for large tool sets. **Applicable: YES** — The Construct: we load dozens of MCP servers (Higgsfield alone exposes 150+ tools); route to a tool first, then load its schema, and measure tokens per run before and after. PRAGMA: vendor-backed advice for clients whose agents slow down as they add connectors.

5. **LangChain puts LangSmith Tool Gateway in public beta (Nov 19): one control point for agent tool calls across MCP clients, Claude Code and Cursor included** ([langchain.com](https://langchain.com/blog/langsmith-tool-gateway)) — The gateway centralizes credentials, per-tool access policies, human approvals and audit traces for the tools agents call, and fronts MCP servers for any MCP-compatible client. **Applicable: YES** — The Construct: our MCP fleet (Higgsfield, Gmail, Drive, Slack, Canva, render nodes) has credentials spread across clients with no single audit trail; a gateway layer, LangSmith or self-built, gives per-agent scopes, approvals for writes and one log, the same pattern as Walmart's Agent Gateway. PRAGMA: a ready reference architecture for clients worried about agents holding live credentials.

**PRAXIS lesson:** Cheap model routing is now a data-handling decision: canary tests showed some inference hosts log prompts despite zero-retention flags. The Construct should pin providers for every worker, enforce ZDR, and keep secrets and client files out of prompts sent to low-cost routes, the same way a shop controls which vendors see a customer's artwork.
