1. **MCP reference servers v2.6.0 (Nov 27) patches 8 more flaws in the Git, Fetch, Memory and Filesystem sample servers; the worst lets Git LFS run programs named in repo settings through the read-only git_status tool** ([aimatter.in](https://aimatter.in/2026/11/27/mcp-servers-release-patches-8-security-flaws/)) — Fixed versions are Git 2026.11.27, Fetch 2026.11.27, Memory 2.2.2 and Filesystem (Windows) 2.4.1; the release finishes two fixes the Nov 11 v2.4.0 release left open, and the mixed date/semver numbering means a generic npm/pip update can silently keep a vulnerable version (single secondary report; the Nov 17 upgrade guide documents the same version-pin trap). **Applicable: YES** — The Construct: a sweep of the connected folders found the reference servers only in a graphify test fixture, so check the Claude desktop and Hermes MCP launch configs directly and pin any mcp-server-git/fetch/memory/filesystem entry to an explicit fixed version, never 'latest'. PRAGMA: 'pin your MCP servers and re-test out-of-scope reads' is a five-minute client audit item.

2. **arXiv 2611.31756 TACT-Bench (Nov 24): multi-turn, adaptive conversational attacks push tool-use agents into failures far more than single-shot ones, and current defenses barely help** ([arxiv.org](https://arxiv.org/abs/2611.31756)) — Across six assistant models the adaptive attacker raised the attack-induced failure rate 17.5% over four baselines, a trust-building variant added another 17.0%, and the two tested defenses cut failures only 8.4-9.4% (preprint, code on GitHub). **Applicable: YES** — The Construct and Brand 9 Signs: any agent that talks to outsiders over several turns (B9 customer email, Vector logo designer, partner chat) needs hard limits on which tools a conversation can unlock, not just a prompt-level refusal. PRAGMA: run TACT-Bench-style multi-turn red-team scripts in client agent audits.

3. **Agentic attacks keep landing through trusted vendor apps: Storm-0940 used the ARTEX multi-agent framework and a compromised ConnectWise app identity to hit 2,250+ Microsoft 365 tenants (Oct 22 report; further Microsoft coverage Nov 26)** ([www.csoonline.com](https://www.csoonline.com/article/4239028/china-linked-hackers-used-agentic-ai-in-attack-on-2-250-microsoft-365-tenants.html)) — The agents signed in through already-consented vendor app identities with no user sign-in, ran about 2,900 attempts per minute and reached privileged cloud access in under three hours in some tenants; Microsoft says to search tenants by app ID, keep affected connections off and preserve Entra/SIEM logs. **Applicable: MAYBE** — Brand 9 Signs / The Construct: review which third-party apps hold OAuth access to the B9 Google Workspace and Microsoft accounts and drop any that are unused. PRAGMA: 'your vendor integrations are now an AI-speed attack surface' is a concrete talking point for operator clients.

**PRAXIS lesson:** A green update is not a patched system: MCP's own reference servers mix date and semantic version numbers, so a routine update can leave the vulnerable build running. The Construct should pin every MCP server to an explicit fixed version and prove the fix with an out-of-scope read test, and treat multi-turn chats with outsiders as an attack path that only tool-level limits close.
