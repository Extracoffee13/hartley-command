1. **The MCP 2026-07-28 spec Release Candidate lands — the biggest protocol revision since launch, with a stateless core, Tasks, and MCP Apps** ([blog.modelcontextprotocol.io](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/)) — the RC delivers a stateless protocol core that scales on ordinary HTTP infrastructure, an Extensions framework, a **Tasks** extension for long-running work, **MCP Apps** for server-rendered UIs inside the client, OAuth/OIDC-aligned authorization hardening, and a formal deprecation policy; beta SDKs for Python, TypeScript, Go, and C# are already out ahead of the final Jul 28 publish. **Applicable: YES** — MCP is the substrate the entire Construct fleet runs on, so this reshapes the harness: a stateless core means our servers run on cheap commodity HTTP infra, Tasks gives first-class long-running jobs (our daily/weekly scans, video/render pipelines) instead of hacked-around timeouts, and MCP Apps let a Construct server render its own dashboard UI. Start testing the beta SDKs now and plan the migration before Jul 28.

2. **SpaceXAI ships Grok 4.5 — an "Opus-class" coding/agentic model at ~4x the token efficiency and a third of the price** ([techcrunch.com](https://techcrunch.com/2026/07/08/spacexai-releases-grok-4-5-which-elon-describes-as-an-opus-class-model/)) — launched Jul 8, trained alongside Cursor, Grok 4.5 posts Terminal-Bench 2.1 83.3% (vs Opus 4.8's 78.9%) while trailing slightly on SWE-Bench Pro (64.7% vs 69.2%); the headline is efficiency — ~15,954 output tokens per SWE-Bench Pro task vs Opus 4.8's 67,020 in max-effort mode (a 4.2x gap) — priced at \$2/\$6 per 1M in/out, EU availability expected mid-July. **Applicable: MAYBE** — for high-volume Construct jobs the token-efficiency-times-price gap is a real cost lever, so benchmark it as a routed option for coding/agentic tasks behind provider-agnostic routing; don't re-tool around it (SWE-Bench Pro still favors Opus, and it's not GA in the EU).

3. **Anthropic moves Cowork to web + mobile with remote sessions, and adds Microsoft 365 write tools** ([testingcatalog.com](https://www.testingcatalog.com/anthropic-brings-claude-cowork-to-web-and-mobile-for-max-users/)) — Cowork sessions now run remotely (beta) and are saved to your Claude account, so work continues with the laptop closed and **scheduled tasks run with no device online**; the rollout starts with Max and expands; separately, new Microsoft 365 write tools let Claude draft/send email, manage calendar events, and create/update OneDrive and SharePoint files. **Applicable: YES** — remote Cowork sessions directly fix the Construct's biggest operational fragility: our scheduled scans (this one included) no longer depend on a Mac being awake. The M365 write tools widen the operator surface PRAGMA can automate for regulated clients living in Microsoft's stack.

4. **arXiv: "Context Engineering — From Prompts to Corporate Multi-Agent Architecture" frames context as the agent's operating system** ([arxiv.org/2603.09619](https://arxiv.org/abs/2603.09619)) — the paper proposes five context-quality criteria (relevance, sufficiency, isolation, economy, provenance) and a cumulative maturity pyramid: prompt engineering → context engineering → intent engineering → specification engineering, drawing on Google ADK, Anthropic, and LangChain architectures. **Applicable: YES** — a direct rubric for how we build CLAUDE.md, the memory tiers, and per-agent context: score every context payload on economy (don't over-stuff) and provenance (cite the source), and treat isolation as the guardrail that keeps one agent's memory from polluting another's. Reinforces the two-tier memory design already in play.

5. **Vertical "read-the-filings" agents keep pulling capital — LinqAlpha raises a \$22M Series A for finance-document agents** ([techstartups.com](https://techstartups.com/2026/07/06/venture-capital-startup-funding-roundup-july-6-2026/)) — announced Jul 2 and anchored by AVP, Atinum, and GFT Ventures, LinqAlpha builds agents that process filings, transcripts, and news for hedge funds and asset managers; it led an otherwise-quiet holiday week (~\$37M in disclosed agent rounds). **Applicable: MAYBE** — signal, not a tool: capital is rewarding narrow agents that ingest a specific document corpus and turn it into decisions — adjacent to Prism's alt-data/diligence remit. The lesson for The Construct is the wedge shape (own one corpus deeply), not the vertical; finance is taken, but signage/real-estate document intelligence is open.
