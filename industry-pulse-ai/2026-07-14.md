2. **arXiv: "From Prompts to Contracts — Harness Engineering for Auditable Enterprise LLM Agents" (Jul 9) reframes production agents as code, manifests, schemas, and validation artifacts, not clever prompts** ([arxiv.org](https://arxiv.org/abs/2607.08028)) — the paper argues enterprise agents start as prompt-carried prototypes but productizing them demands source boundaries, entity routing, answer contracts, and reproducible traces; it moves deterministic behavior out of the prompt and into code/manifests/schemas/validation so every answer is traceable and auditable. **Applicable: YES** — this is PRAGMA's durable moat stated plainly: the sellable deliverable for AI-operator clients is an *auditable* agent (deterministic logic in code + reproducible traces), not a prompt-clever demo. It also disciplines The Construct's own fleet — push each agent's non-negotiable behavior into manifests/schemas and keep the prompt for judgment only.
