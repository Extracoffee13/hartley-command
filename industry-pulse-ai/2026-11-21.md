Brand 9 Signs: no-API vendor portals become automatable on either stack. PRAGMA: clients will ask which desktop agent to pick, so have a side-by-side ready.

5. **OpenAI details Performance Factory (Nov 19): Codex agents diagnose ChatGPT slowdowns and propose fixes for engineers to approve** ([openai.com](https://openai.com/index/how-openai-performance-factory-keeps-chatgpt-fast/)) — OpenAI describes an internal system where Codex agents investigate latency regressions in ChatGPT, find the cause and propose fixes, with engineers reviewing before anything ships; Databricks shipped the same pattern for data jobs as Genie ZeroOps the same day. **Applicable: YES** — The Construct: two vendors converged on 'agent diagnoses, proposes a fix as a PR, human approves', which is the right template for the site-health sentinel and scheduled-task triage agents (they should open a fix, not just report). PRAGMA: a citable, primary-source example of safe self-healing ops. Brand 9 Signs: brand9signs.com site repairs via the sentinel.

**PRAXIS lesson:** This week the big platforms converged on three patterns at once: desktop agents (Claude and Gemini both drive the Mac now), one gated, logged path for every tool call, and agents that propose fixes for a human to approve rather than acting alone. For The Construct, the drivers are becoming interchangeable, so invest in the gate (own identity per worker, one logged MCP gateway) and in fix-as-PR loops for the sentinel agents, not in any one vendor's agent.
