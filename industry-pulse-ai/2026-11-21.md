1. **Anthropic ships Claude Ship (Nov 23): three GitHub pull-request agents, with Code Review GA and PR Steward + Approvals in public beta, plus a /ship command in Claude Code** ([marktechpost.com](https://www.marktechpost.com/2026/11/23/anthropic-claude-ship-pull-request-agents)) — The agents review, fix and shepherd pull requests on GitHub; Anthropic says most reviews finish in 6-10 minutes. **Applicable: YES** — The Construct: put Code Review and PR Steward on the hartley-command and B9 site repos so the sentinel agents' fixes land as reviewed PRs, not direct pushes, which is the fix-as-PR loop we flagged last week. PRAGMA: a ready reference for 'agents propose, humans approve' in client engineering teams.

2. **Google gives the Gemini Mac app computer use (Nov 19): it can operate Mac apps, fill forms and organize local files** ([blog.google](https://blog.google/innovation-and-ai/products/gemini-app/computer-use-mac/)) — Google's Gemini app for Mac can now carry out multi-step tasks across desktop apps and websites, starting in English for US Google AI Plus, Pro and Ultra subscribers. **Applicable: MAYBE** — The Construct: with Claude computer use opening to Team/Enterprise the same week, desktop agents are now a two-vendor commodity, so the moat is our runbooks and gates (Signs365 cart steps, vendor portals), not the driver; keep runner tasks vendor-neutral. Brand 9 Signs: no-API vendor portals become automatable on either stack. PRAGMA: clients will ask which desktop agent to pick, so have a side-by-side ready.

3. **Canva MCP is generally available, with new REST APIs and a command-line tool so AI agents can create and edit Canva designs** ([canva.com](https://www.canva.com/newsroom/news/canva-mcp-update/)) — Canva moves its MCP server out of preview and adds developer APIs and a CLI aimed at agents and coding tools. **Applicable: YES** — Brand 9 Signs: Canva is already connected in Cowork, so a design agent can draft sign mockups, social posts and client proofs straight into Canva brand templates. The Construct: a GA, supported design MCP is safer to build standing jobs on than preview tools.

4. **Google ships semantic governance policies in Preview (Nov 23): a judge LLM checks every tool call an agent proposes and blocks it before it runs if it breaks a plain-language company rule or doesn't match the user's request** ([helpnetsecurity.com](https://www.helpnetsecurity.com/2026/11/23/google-semantic-governance-policies/)) — The check sits outside the agent at an enforcement point such as Agent Gateway; the user-intent check is on by default, verdicts and rationale go to Cloud Logging, and Google recommends dry-run first because LLM verdicts can vary. **Applicable: YES** — The Construct: the same pattern fits our MCP fleet, a pre-execution gate that reads each send/order/publish call against written rules and logs the verdict, sitting outside Hermes and Cowork rather than in their prompts. PRAGMA: a big-vendor reference design for the 'policy outside the agent' layer we sell.

5. **OpenAI details Performance Factory (Nov 19): Codex agents diagnose ChatGPT slowdowns and propose fixes for engineers to approve** ([openai.com](https://openai.com/index/how-openai-performance-factory-keeps-chatgpt-fast/)) — OpenAI describes an internal system where Codex agents investigate latency regressions in ChatGPT, find the cause and propose fixes, with engineers reviewing before anything ships; Databricks shipped the same pattern for data jobs as Genie ZeroOps the same day. **Applicable: YES** — The Construct: two vendors converged on 'agent diagnoses, proposes a fix as a PR, human approves', which is the right template for the site-health sentinel and scheduled-task triage agents (they should open a fix, not just report). PRAGMA: a citable, primary-source example of safe self-healing ops. Brand 9 Signs: brand9signs.com site repairs via the sentinel.

**PRAXIS lesson:** This week the big platforms converged on three patterns at once: desktop agents (Claude and Gemini both drive the Mac now), one gated, logged path for every tool call, and agents that propose fixes for a human to approve rather than acting alone. For The Construct, the drivers are becoming interchangeable, so invest in the gate (own identity per worker, one logged MCP gateway) and in fix-as-PR loops for the sentinel agents, not in any one vendor's agent.
