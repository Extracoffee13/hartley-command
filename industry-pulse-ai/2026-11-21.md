Brand 9 Signs: no-API vendor portals become automatable on either stack. PRAGMA: clients will ask which desktop agent to pick, so have a side-by-side ready.

3. **OpenAI: its agents now finish 46% of research tasks sized at 2-4 human hours (23% in March) and 35% of 4-8 hour tasks (13%); "Dots" always-on agents in limited test (Nov 21-22)** ([aiagentstore.ai](https://aiagentstore.ai/ai-agent-news/this-week)) — OpenAI's own numbers show multi-hour agent task completion roughly doubling in eight months, while it tests persistent background agents for some ChatGPT Plus and Business users. **Applicable: MAYBE** — The Construct: half-day jobs (shop SEO sweeps, bid prep, site audits) are now realistic to hand to one agent run, but still fail more often than not, so keep the verification gates. PRAGMA: a dated benchmark to set client expectations on what an agent can own end to end.

4. **"Formalize or Lose It" (Nov 23): nearly half of supervisory rules in multi-agent runs lived only in prompts, and executable checks caught failures prompt-only supervision missed; Tether 0.4.0 (Nov 22) replays recorded agent runs as tests** ([aiagentstore.ai](https://aiagentstore.ai/ai-agent-news/this-week)) — New research plus an open test harness point the same way: rules an agent must follow should be code that checks the run, and recorded runs can be replayed to assert tool calls, final files and step/cost limits. **Applicable: YES** — The Construct: move written gates (done-means-done, claims-truth, print-file guide) from SKILL.md prose into scripts that fail the run, and replay a saved run of each standing agent after any skill edit. PRAGMA: a citable reason to sell verification harnesses, not just prompts.

5. **OpenAI details Performance Factory (Nov 19): Codex agents diagnose ChatGPT slowdowns and propose fixes for engineers to approve** ([openai.com](https://openai.com/index/how-openai-performance-factory-keeps-chatgpt-fast/)) — OpenAI describes an internal system where Codex agents investigate latency regressions in ChatGPT, find the cause and propose fixes, with engineers reviewing before anything ships; Databricks shipped the same pattern for data jobs as Genie ZeroOps the same day. **Applicable: YES** — The Construct: two vendors converged on 'agent diagnoses, proposes a fix as a PR, human approves', which is the right template for the site-health sentinel and scheduled-task triage agents (they should open a fix, not just report). PRAGMA: a citable, primary-source example of safe self-healing ops. Brand 9 Signs: brand9signs.com site repairs via the sentinel.

**PRAXIS lesson:** This week the big platforms converged on three patterns at once: desktop agents (Claude and Gemini both drive the Mac now), one gated, logged path for every tool call, and agents that propose fixes for a human to approve rather than acting alone. For The Construct, the drivers are becoming interchangeable, so invest in the gate (own identity per worker, one logged MCP gateway) and in fix-as-PR loops for the sentinel agents, not in any one vendor's agent.
