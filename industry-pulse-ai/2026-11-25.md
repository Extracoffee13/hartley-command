# Industry Pulse — AI / Agent Ecosystem · 2026-11-25

Daily scan for The Construct. Source URL · one-line summary · applicable to The Construct.

1. **Anthropic MCP update (Nov 24): Skills over MCP in public beta; Tasks and Elicitation now generally available; File Uploads coming soon** ([claude.com](https://claude.com/resources/articles/skills-over-mcp-tasks-and-more)) — MCP servers can now ship skills alongside their tools, long-running Tasks and mid-call Elicitation (the server asking the user a question) are GA, and file uploads over MCP are next. **Applicable: YES** — The Construct: package our skills (b9-*, vironbox-*, hermes-*) with the MCP servers that use them, so any agent that connects gets both the tool and the instructions; use Tasks for long jobs (renders, partner orders) and Elicitation for owner sign-off. PRAGMA: a cleaner way to hand clients a tool and its playbook together.

2. **Signal joins United Airlines and JPMorgan Chase in limiting AI agents on their services over customer risk (Nov 24)** ([cnbc.com](https://www.cnbc.com/2026/11/24/signal-airlines-banks-ai-limit.html)) — Large consumer brands are starting to restrict or block AI agents acting for customers on their services. **Applicable: YES** — The Construct: Hermes/browser runners that sign in to third-party sites (partner portals, banks, airlines) should expect blocks and need a fallback to official APIs or a human step. Brand 9 Signs: decide on purpose whether the shop welcomes agent buyers. PRAGMA: an 'agent access policy' is now a real client question.

3. **Mesh launches Mesh MCP (Nov 24): a hosted, read-only MCP server that lets coding agents build a payments integration from one prompt** ([prnewswire.com](https://www.prnewswire.com/news-releases/mesh-launches-mesh-mcp-turning-one-prompt-into-a-payments-integration-302949189.html)) — Works with Claude Code, Claude, Cursor and Codex; it reads docs and account setup but never moves funds. **Applicable: MAYBE** — Brand 9 Signs / The Construct: a model for how payment tooling should be exposed to agents (read-only by default, money moves only through a gated path); worth copying for Stripe and shop-order agents rather than adopting Mesh itself.

The Construct: re-run the weekly ChatGPT shopping prompt measure against the new default model.

5. **Agent accountability and security money keeps flowing: Dante Security exits stealth with a $10M seed (NFX) and Metano raises $12M (Nov 24)** ([thenextweb.com](https://thenextweb.com/news/dante-security-10m-ai-agent-accountability)) — Investors are funding tools that track and audit what AI agents do, as agents outpace existing security tools. **Applicable: MAYBE** — PRAGMA: agent audit trails are becoming a bought category, so lead client pitches with logging and accountability. The Construct: keep a per-agent action log as a standing requirement for every runner.

**PRAXIS lesson:** Two signals landed the same day: Anthropic made MCP able to carry skills and ask the user questions mid-task, while Signal, United and JPMorgan started limiting outside agents. The Construct should move its agents onto sanctioned MCP and API paths, with skills bundled and sign-off asked in-band, and treat scraping a site through a browser as a fallback that can stop working any day.
