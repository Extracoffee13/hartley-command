# Industry Pulse — AI / Agent Ecosystem · 2026-11-23

Daily scan for The Construct. Source URL · one-line summary · applicable to The Construct.

1. **1Password for Agents: agents sign in to sites without ever seeing the password, with a Claude integration and approvals that expire after 30 days (week of Nov 23)** ([1password.com](https://1password.com/personal-ai-agent-integrations)) — 1Password now brokers logins for AI agents so the agent gets a session, not the secret; its Claude integration adds an Agentic Mode, and each grant lapses after 30 days unless renewed. **Applicable: YES** — The Construct: Hermes, Cowork and the B9 partner-order runner currently drive logged-in sessions (Signs365, WordPress, Google) with credentials held in browser profiles and files; moving those logins behind a broker gives per-agent grants, expiry and revocation without pasting passwords into prompts. PRAGMA: the cleanest answer to a client's first question, "what happens to our passwords?"

2. **Wells Fargo changes its online access agreement (effective Nov 24): customers use third-party AI agents at their own risk; JPMorgan, Schwab and Citi already block or limit credential-based agents** ([killtheai.com](https://killtheai.com/news/top-10-ai-news-today-november-23-2026/)) — Big US banks are pushing liability for agent logins onto customers and shutting out agents that sign in with a customer's username and password. **Applicable: YES** — Brand 9 Signs: any agent task touching business banking (reconciliation, payments, pulling statements) should go through bank APIs, exports or a bookkeeping connector, not a scripted login; a credential-based bank session may now void protections. PRAGMA: a dated, concrete risk to put in every client's agent-permissions policy.

3. **SWE-CoWork benchmark: frontier coding agents pass about 63% of tests inside a simulated company but fully finish under 8% of assignments** ([explainx.ai](https://explainx.ai/blog/swe-cowork-coding-agents-digital-employees-benchmark-2026)) — A new benchmark drops 11 models into a simulated workplace; Claude Opus 5.5 and GPT-6 Astra clear most individual checks yet rarely complete a whole assignment end to end. **Applicable: YES** — The Construct: matches what our own runs show: partial progress is common, full completion is not. Grade agents on finished, verified deliverables (the done-means-done gate), not on steps passed, and keep a human checkpoint before anything ships. PRAGMA: a sober data point for setting client expectations on unattended agents.

4. **Claude Code v2.1.328: sessions with no permission mode now start in auto mode, auto mode reaches Bedrock, Google Cloud and Microsoft Foundry, and MCP tool hooks can block on failure** ([dev.to](https://dev.to/aicoding-guide/this-week-in-claude-code-codex-and-gemini-cli-week-of-november-22-2026-1ofi)) — Interactive Claude Code sessions default to auto mode, the mode is available on the major cloud providers and the Claude apps gateway, and an mcp_tool hook option "onFailure": "block" stops a run when a guarded MCP call fails. **Applicable: YES** — The Construct: check that every Claude Code launch we script (render nodes, site deploy, Hermes workers) sets its permission mode explicitly, since the default just changed; use onFailure: block on write-capable MCP tools so a failed guard halts the run instead of letting it continue.

5. **Google Agent Compute Engine: managed VMs for agents with checkpointed sessions** ([theneuron.ai](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-monday-november-23-2026/)) — Google is offering managed virtual machines built for agent workloads, where an agent's session can be checkpointed and resumed rather than rebuilt after a crash or timeout. **Applicable: MAYBE** — The Construct: long jobs (Vironbox renders, multi-hour site sweeps) currently die with the shell or container; checkpointed agent sessions are the pattern to copy, whether on Google or by saving state to disk between steps. Worth a trial only if a render or research job keeps losing progress.

**PRAXIS lesson:** Agents are being cut off from passwords from both sides: banks are blocking or disclaiming agents that log in with customer credentials, and credential brokers now give agents a scoped, expiring session instead. The Construct should move every logged-in agent task to an API, a connector or a brokered session with expiry, and stop handing agents raw passwords.
