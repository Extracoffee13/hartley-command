1. **Anthropic opens a directory submission portal for Claude plugins (MCP connectors + Skills), with MCP 2.0 support** ([source](https://claude.com/blog/build-plugins-for-claude)) — Announced 25 Sep: developers on paid plans can submit a single remote MCP connector or a GitHub-hosted plugin bundle (MCP servers + skills; in Claude Code also hooks, commands, agents) at claude.ai/directory/manage, get automatic validation and a safety scan, track review, choose when to publish, then see installs by surface/version and which searches lead to the listing. Claude supports the MCP 2.0 spec (stateless core) plus MCP Apps and Enterprise Managed Auth; one discovery experience across Claude and Claude Code rolls out over the coming weeks. **Applicable: YES** — The Construct's skills are already plugin-shaped; bundling a public, non-credentialed PRAGMA plugin (AI-visibility audit skills + a read-only MCP) gets it listed where buyers already search, and the search-term analytics tell us what people look for. Keep internal/credentialed skills private.

2. **Google tests "Call for Me": Gemini phones local businesses for you, navigates menus, waits on hold and talks to staff** ([source](https://techcrunch.com/2026/09/24/google-tests-letting-gemini-make-phone-calls-initially-for-us-pixel-owners/)) — Reported 24–25 Sep: an experimental Pixel 11 feature (US, paid Gemini, Phone by Google beta) where Gemini calls from the user's own number to check inventory, change appointments or ask about reservations, with a live transcript the user can take over; it refuses payments, passwords and SSNs. **Applicable: MAYBE** — Brand 9 Signs' phone line will start getting AI callers asking price, lead time and availability. Whoever answers (person or voicemail) should have a short, consistent script with the facts an agent can repeat; for PRAGMA, 'what does an AI hear when it calls you' is a new visibility surface next to 'what does an AI say about you'.

3. **Anthropic signs a 7-year, $11.6B CPU-focused cloud deal with Akamai (up to ~$20B, warrant for up to 5% of Akamai)** ([source](https://techcrunch.com/2026/09/25/anthropic-to-pay-akamai-11-6-billion-over-seven-years-in-cloud-deal/)) — Announced 25 Sep (Akamai 8-K): the largest deal in Akamai's history and unusual for centering on CPUs rather than GPUs, the general-purpose compute that runs agent tool calls, sandboxes and code execution. Reports put Anthropic's compute commitments past $500B in under a year. **Applicable: NO** — No action for The Construct. Context only: more CPU capacity behind agent sandboxes should mean fewer capacity-related failures in long Cowork/Claude Code runs over time.

4. **arXiv: "When Should Forecasting Agents Reason? Behavioral Stress Tests for Reliability Routing"** ([source](https://arxiv.org/abs/2609.28475)) — New this week (arXiv 2609.28475): stress-tests forecasting agents that mix LLM reasoning, retrieval, ensembling and calibration to find when each behavior actually helps, and proposes routing questions to the behavior that is reliable for them rather than always reasoning. **Applicable: MAYBE** — Same question The Construct faces with the Mirror/visibility scans and Lens: not every job needs a full reasoning pass. Useful framing for deciding which daily jobs get the expensive model and which get a cheap deterministic check.

**PRAXIS lesson:** Anthropic made plugins the single way to extend Claude and now shows developers which searches lead people to a listing, and Google's Gemini will start phoning businesses directly. Both are the same shift PRAGMA sells: agents choose what to use and whom to call, so The Construct should publish one public PRAGMA plugin and give Brand 9 a fixed set of facts that any caller, human or AI, hears the same way.
